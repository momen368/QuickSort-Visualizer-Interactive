▥How Quick Sort Works
01. Choose a Pivot
Select an element from the array to serve as the pivot point (often the last element).
02. Partition
Rearrange elements so smaller items go to the left and larger items go to the right of the pivot.
03. Place Pivot
Put the pivot element into its final sorted position in the array.
04. Recursion
Recursively apply the above steps to the sub-arrays on the left and right of the pivot.

  
▥Complexity & Characteristics
Best Case TimeO(n log n)
Average Case TimeO(n log n)
Worst Case TimeO(n²) (Poor pivot choice)
Space ComplexityO(log n) auxiliary
